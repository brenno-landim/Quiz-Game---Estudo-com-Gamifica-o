# 🏴‍☠️ Quiz de Estudos com Gamificação

## 🎮 Sobre o projeto

A gamificação é uma das melhores formas de se engajar em algo, e no aprendizado não é diferente. A ideia deste quiz é focar no aprendizado de determinado conteúdo com algo de que o usuário goste, neste exemplo, o anime One Piece. 🍖⚓

## 📚 Como funciona

Ao colocar PDFs (no máximo 10) 📄, o jogo cria questões de acordo com a quantidade e a dificuldade escolhidas pelo usuário. Os personagens são escolhidos aleatoriamente (todos de One Piece, obviamente) 🎲. A cada acerto, você golpeia o seu adversário ⚔️; a cada erro, você é golpeado 💥. O objetivo é deixar o estudo de conteúdos maçantes mais divertido 😄, embora não possamos esquecer o mais importante: aprender 🧠.
